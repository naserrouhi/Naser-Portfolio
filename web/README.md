# Portfolio Workbench web client

The server-rendered Next.js client for Naser Rouhi's portfolio. It provides the
responsive IDE workbench, eight locale routes, theme support, structured SEO data,
and resilient access to the .NET portfolio API.

See the repository-level [`README.md`](../README.md) for architecture, setup,
verification, and Docker instructions.

```powershell
& npm.cmd ci
& npm.cmd run dev
& npm.cmd run lint
& npm.cmd run typecheck
& npm.cmd run test
& npm.cmd run build
```
